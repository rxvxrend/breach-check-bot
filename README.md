# Breach Check Bot

Telegram-бот для проверки утечек данных с системой мониторинга и уведомлений.

## Возможности

- Проверка **Email**, **Username** и **Password** через внешние чекеры.
- Красивый формат ответа с количеством найденных утечек.
- Подписка на мониторинг конкретного значения после проверки.
- Фоновая проверка подписок (раз в час) с уведомлением о новых утечках.
- Просмотр и удаление подписок через меню бота.
- Локальное хранение подписок в SQLite.

## Стек

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/)
- aiohttp
- python-dotenv
- SQLite

## Структура проекта

```text
bot/
  handlers/              # Обработчики команд, сообщений и callback-кнопок
  keyboards/             # Клавиатуры Telegram
  services/
    checkers/            # Чекеры по типам сущностей (email/username/password)
    formatters/          # Форматирование результатов
    database.py          # Работа с SQLite
    monitoring.py        # Фоновый цикл мониторинга подписок
    registry.py          # Реестр доступных чекеров
    http_client.py       # Общий HTTP-клиент
    storage.py           # Инициализация БД
  states/                # FSM-состояния aiogram
  config.py              # Загрузка BOT_TOKEN из .env
  main.py                # Точка входа
```

## Быстрый старт

### 1) Клонирование и установка зависимостей

```bash
git clone https://github.com/rxvxrend/breach-check-bot.git
cd breach-check-bot
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

### 2) Настройка окружения

Создай `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token
```

> Токен можно получить у [@BotFather](https://t.me/BotFather).

### 3) Запуск

```bash
python bot/main.py
```

После запуска бот:

- поднимет polling,
- создаст/использует файл БД `breach_bot.db` в корне проекта,
- запустит фоновый мониторинг подписок.

## Как пользоваться

1. Нажми `/start`.
2. Выбери тип проверки: **🔑 Пароль**, **📧 Email** или **👤 Username**.
3. Отправь значение для проверки.
4. Получи результат и (при необходимости) добавь значение в мониторинг.
5. Раздел **📂 Мои подписки** покажет текущие подписки; оттуда можно отписаться.

## Мониторинг

- Фоновый цикл выполняется каждый час.
- Для каждой подписки бот повторно запускает соответствующий checker.
- Если количество найденных утечек выросло, бот отправляет уведомление и обновляет `last_count` в БД.

## Важно

- Не публикуй `.env` и токен бота в репозитории.
- Для продакшена лучше добавить:
  - логирование в файл/агрегатор,
  - systemd/supervisor/docker для автоперезапуска,
  - резервное копирование SQLite.
